# 🚴 Velo Rush 2.5D

Браузерная гонка на велосипедах с видом сверху под наклоном (2.5D): соперники-боты, магазин реальных велосипедов, улучшения, колёса под разные покрытия и 8 трасс.

## Запуск

Сборка не нужна, только чистый HTML/JS/Canvas.

```bash
python3 -m http.server 8000      # или любой статический сервер
# открыть http://localhost:8000
```

Можно открыть и сам `index.html` двойным щелчком.

**Управление:** ↑/W — педали, ↓/S/Пробел — тормоз, ←/→ или A/D — руль, Shift — спурт (тратит энергию), R — вернуться на трассу, Esc — пауза. На телефоне появляются сенсорные кнопки.

**Улучшения** (6 веток по 5 уровней): облегчение, трансмиссия, аэродинамика, тормоза, руль и геометрия, подвеска.

Например Continental GP5000, Zipp 404, Schwalbe G-One, WTB Riddler, Maxxis Minion DHF, шипованные Schwalbe Ice Spiker и 45NRTH Dillinger. Для каждого покрытия у покрышки свой накат и своё сцепление.

| Загородное шоссе | асфальт | скорость |
| Городской критериум | асфальт + брусчатка, повороты на 90° | управляемость, разгон |

Следующая трасса открывается, когда вы займёте место в тройке на предыдущей. В меню для каждой трассы показан прогноз: время круга и «звёзды» для вашего велосипеда.

## Фотографии велосипедов

Фото настоящих моделей ищутся на **Wikimedia Commons** (свободные лицензии). Под каждым фото подписаны автор и лицензия со ссылкой на страницу файла.

* Онлайн игра сама находит фото через API Commons и кэширует результат в браузере.
* Чтобы фото работали офлайн и лежали в репозитории, выполните (нужен Node 18+ и интернет):

  ```bash
  node tools/fetch-photos.mjs
  ```

  Скрипт скачает изображения в `assets/photos/` и запишет авторов и лицензии в `assets/photos/credits.js`.
* Без сети показывается нарисованная иллюстрация велосипеда нужного типа.

## Структура

```
index.html          интерфейс и HUD
css/style.css       стили
js/data.js          велосипеды, колёса, улучшения, трассы, покрытия
js/state.js         сохранение (localStorage), итоговые характеристики, физическая модель
js/track.js         сплайн трассы, покрытия, декорации, оценка времени круга
js/render.js        2.5D-камера и отрисовка (дорога, здания, деревья, гонщики)
js/race.js          физика, ИИ соперников, круги, финиш
js/photos.js        фото с Wikimedia Commons и запасные иллюстрации
js/ui.js            меню: трассы, гараж, магазин, результаты
js/main.js          игровой цикл, управление, HUD
tools/fetch-photos.mjs  скачивание фото в репозиторий
```
