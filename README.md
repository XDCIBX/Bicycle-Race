# 🚴 Velo Rush 2.5D

Велогонка с видом сверху под наклоном (2.5D). Велосипед **едет сам**, а результат зависит от характеристик велосипеда, колёс, тренированности гонщика и выбранной тактики. Все велосипеды и покрышки — реальные модели реальных брендов.

Работает в браузере, ставится на iPhone как приложение (PWA) и собирается в нативное iOS-приложение через Capacitor.

## 📱 На iPhone

### Вариант 1: PWA, без Mac и App Store

1. Включите GitHub Pages: **Settings → Pages → Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` опубликует игру по адресу `https://<владелец>.github.io/<репозиторий>/`.
2. Откройте этот адрес в Safari на iPhone, затем **Поделиться → «На экран „Домой“»**.
3. Игра запускается на весь экран со своей иконкой и работает офлайн: сервис-воркер кэширует и игру, и фото велосипедов.

### Вариант 2: нативное приложение (нужен Mac с Xcode)

Xcode-проект уже лежит в `ios/`.

```bash
npm install
npm run ios:sync      # собирает www/ и копирует его в ios/
npm run ios:open      # открывает проект в Xcode → выбрать iPhone → Run
```

Перед запуском на устройстве в Xcode выберите свою команду в *Signing & Capabilities*. Для публикации в App Store нужна учётная запись Apple Developer.

## Как играть

* **Велосипед едет сам.** Он сам держит траекторию, тормозит в поворотах и обходит соперников. Исход решают велосипед, колёса, навыки гонщика и тактика.
* **Тактика** выбирается перед стартом:
  * ⚖️ **Ровный темп**;
  * 🔥 **Атака со старта**;
  * 🏁 **Финишный рывок** — экономит силы за спинами соперников («на колесе») и выкладывается в конце.
* **⚡ Спурт** (или Пробел) — рывок на 4 секунды. **×1/×2/×4** ускоряет время (F), **⏸** — пауза (Esc).

## 🧑 Уровни и дерево навыков

* За гонки, тренировки и чемпионаты начисляется **опыт**. Уровней 50, за каждый новый уровень даётся бонус монет.
* Каждый уровень даёт **очко навыков**, и ещё одно бонусное — каждые 5 уровней.
* **Дерево навыков** — 5 веток, 21 навык. Каждый навык открывается с определённого уровня и только после предыдущего в своей ветке:

| Ветка | Навыки |
|---|---|
| 🚀 Спринтер | Взрывной старт → Финишёр → Длинный спурт → Король спринта |
| ⛰️ Горняк | Лёгкий вес → Ритм в гору → Бесстрашный спуск → Король гор |
| 🌲 Технарь | Чувство баланса → Грязь не помеха → Ледяные нервы → Мастер траектории |
| 🧠 Тактик | Чтение гонки → Второе дыхание → Экономный → Лидер пелотона |
| 🏊 Триатлет | Гидрокостюм → Быстрые транзиты → Беговая экономичность → Нутрициолог → Железный человек |

* **Тренировки** за монеты: 6 веток велогонщика и 5 веток триатлета. Потолок тренированности растёт с уровнем гонщика.

## 🏊 Триатлон

Это отдельный режим соревнований. Сначала плавание на озере между буями, затем транзит T1, велоэтап на вашем велосипеде, транзит T2 и бег по парку.

| Соревнование | Дистанция |
|---|---|
| Акватлон | 1 км плавания + 5 км бега |
| Супер-спринт | 0,4 / 10 / 2,5 км |
| Спринт | 0,75 / 20 / 5 км |
| Дуатлон | бег 5 + вело 40 + бег 10 км |
| Олимпийская | 1,5 / 40 / 10 км |
| Ironman 70.3 | 1,9 / 90 / 21,1 км (лимит 8:30) |
| Ironman | 3,8 / 180 / 42,2 км (лимит 17:00) |

* **Характеристики триатлета:** плавание, бег, транзиты, выносливость, питание. Велоэтап зависит от велосипеда (разделочник или аэро здесь сильнее всего) и вело-тренировок.
* **Гликоген:** расходуется по ходу гонки и пополняется на пунктах питания и гелями (кнопка 🍌). Если он кончился, наступает «стена» и скорость падает на 30%.
* **Темп** можно менять прямо в гонке: 🐢 Спокойно / ⚖️ Ровно / 🔥 Мощно.
* Время считается по реальной модели, поэтому финиш Ironman у сильного любителя — около 8–10 часов. Гонка проигрывается ускоренно, кнопка ⏭ перематывает этап.

## 🏆 Чемпионаты и трофеи

* **9 чемпионатов** (6 велосипедных и 3 по триатлону): от «Кубка новичков» до «Гранд-тура», «Чемпионата мира» и «Чемпионата мира Ironman · Кона».
* Состав соперников в чемпионате не меняется от этапа к этапу. Очки за места 1–6: 25 / 18 / 15 / 12 / 10 / 8. После последнего этапа топ-3 общего зачёта получают золотой, серебряный или бронзовый **кубок** и призовой фонд.
* За каждый подиум в любой гонке выдаётся **медаль**.
* На вкладке **«Трофеи»** собраны полка кубков всех чемпионатов, медали по каждой трассе и соревнованию, рекорды и авторы фото.

**Внешний вид велосипедов.** Каждый велосипед рисуется в SVG (`js/bikeart.js`) по настоящей геометрии рамы: стек, рич, углы рулевой и подседельной труб, длина перьев, вынос вилки. На рисунке есть:

* объёмные трубы и декали бренда на раме;
* обода с логотипами (Roval, Zipp, DT Swiss…) и перекрёстная шнуровка спиц;
* протектор, тормозные роторы и трансмиссия;
* амортизационные вилки FOX/RockShox, барашек, райзер или аэробары.

**Настоящие фото** с Wikimedia Commons подгружаются, только если в названии файла есть **и бренд, и модель**. Снимки гонок, команд, выставок, логотипов и крупные планы деталей отбрасываются. Если подходящего фото нет, показывается модель велосипеда.

Подписей поверх изображения нет:

* **ⓘ** — автор и лицензия фото;
* **«Модель / Фото»** — переключатель вида;
* **«✕ не тот»** — убирает неверное фото и ищет следующее.

Чтобы фото лежали в репозитории и работали офлайн, выполните `npm run photos`.

**Улучшения:** облегчение, трансмиссия, аэродинамика, тормоза, руль, подвеска (по 5 уровней).

**Колёса:** 17 реальных покрышек (Continental, Vittoria, Zipp, Schwalbe, Panaracer, WTB, Maxxis, Surly, 45NRTH, Kenda, Odyssey). У каждой свой накат и сцепление на каждом покрытии.

## Трассы

Загородное шоссе · Городской критериум (брусчатка) · Гравийная петля · Горный серпантин · Лесной кросс-кантри · Пустынные дюны · Ледяная тундра · Приморский Гран-при. Следующая трасса открывается, когда вы займёте место в тройке на предыдущей.

На трассах есть озёра и море, ограждения и рекламные щиты у старта, трибуна со зрителями, шатры команд, километровые знаки и покрышки на крутых поворотах. В городе — тротуары, «зебры» и припаркованные машины. По земле плывут тени облаков, а в меню у каждой трассы есть 2.5D-превью.

## Запуск в браузере

```bash
python3 -m http.server 8000   # затем открыть http://localhost:8000
```

## Структура

```
index.html, css/style.css      интерфейс (адаптирован под iPhone: safe area, нижняя панель вкладок)
manifest.webmanifest, sw.js    PWA: установка на экран «Домой», офлайн-кэш
icons/                         иконки приложения
js/data.js                     велосипеды, колёса, улучшения, тренировки, тактики, трассы (вкл. плавательную и беговую)
js/progression.js              опыт и уровни, дерево навыков, медали и кубки, чемпионаты
js/triathlon.js                триатлон: соревнования, модель триатлета, гликоген, гели, этапы
js/state.js                    сохранение, итоговые характеристики, профиль гонщика, физика
js/track.js                    сплайн трассы, покрытия, декорации, оценка времени круга
js/race.js                     автопилот, тактика, энергия, «колесо», круги, финиш
js/render.js                   2.5D-камера и отрисовка (дорога, здания, гонщики)
js/bikeart.js                  реалистичная отрисовка велосипедов по геометрии рам
js/photos.js                   фото с Wikimedia Commons + переключатель «Фото / Модель»
js/ui.js                       меню: гонки, тренировки, гараж, магазин, результаты
js/main.js                     игровой цикл, HUD, кнопки «Спурт» и ускорения
tools/build-www.mjs            сборка www/ для Capacitor и GitHub Pages
tools/fetch-photos.mjs         скачивание фото в репозиторий
ios/                           Xcode-проект (Capacitor)
```
